# QuoteDesk

Purchase request to winning vendor, driven from Claude through MCP. The app has no AI inside: no AI SDKs, no AI keys, no AI calls. Claude (on the customer's own plan) does the thinking.

## What it does
1. The procurement manager tells Claude what to buy. Claude creates a draft purchase request through MCP.
2. Required details are enforced by the app: delivery city, needed-by date, and a quantity and unit of measure for every item. If one is missing, nothing is saved and Claude is told to ask the manager.
3. The manager edits the draft in the app and opens it for quotes with a quote deadline.
4. Vendors log in and quote, or the manager enters a quote on a vendor's behalf.
5. Claude reads the quotes and recommends one. The manager names the winner and Claude records it.
6. Create PO is a disabled placeholder. It marks the handoff to a payments partner and is not built.

The app also has a vendor list and a product catalogue. The catalogue supplies the category and unit of measure when a request is raised.

## Code map
| File | Purpose |
|---|---|
| `src/domain.ts` | All rules: roles, statuses, required details, quotes, award. Used by both the screens and MCP. |
| `src/mcp.ts` | MCP tools: list_prs, create_pr, update_pr, open_for_quotes, list_products, list_vendors, get_quotes, mark_winner |
| `src/web.ts`, `src/views.ts` | Screens for the manager and the vendor, with dark and light mode |
| `src/db.ts`, `src/seed.ts` | Schema, safe upgrades and fictional demo data |

## Run locally
    npm install
    # needs Postgres; default is postgres://postgres@localhost:5433/quotedesk, or set DATABASE_URL
    npm run dev          # http://localhost:3000

## Deploy (Render)
`render.yaml` creates the web service and the Postgres database. Render asks for `MCP_TOKEN` (a long random string of letters and digits, it is part of the connector link). After the first deploy, set `PUBLIC_URL` to the app's https URL with no trailing slash.

| Variable | Value |
|---|---|
| DATABASE_URL | set by the blueprint |
| NODE_ENV | production |
| MCP_TOKEN | a long random string |
| SESSION_SECRET | generated by Render |
| PUBLIC_URL | the app's public https URL |

Tables and demo data are created on first start. Later versions upgrade the tables in place.

## Tests
